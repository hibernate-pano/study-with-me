## 二、修复的问题（本次基线）

### 后端
1. **陈旧 .js 遮蔽 .ts（严重）**：`backend/src/` 下残留 10 个早期 JS 文件（git 跟踪），Node CJS 解析优先 `.js`，导致 ts-node 运行时加载的是旧代码（`getPopularLearningPaths is not a function` 等）。已 git rm 删除，后端现在运行的是真正的 TS 源码。
   - 涉及：`config/index.js`、`index.js`、`routes/{auth,content,exercises,learningPaths,progress,tutor}.js`、`services/{aiService,supabaseService}.js`
2. 依赖安装：171 packages（npm，Node v22.23.2）

### 前端
1. **缺失依赖**（运行时崩溃风险）：安装 `react-confetti`、`react-use`（LearningStreak 使用）、`axios`、`antd`、`@ant-design/icons`（自适应组件使用）、`recharts`（图表组件使用）
2. **MUI v7 Grid 破坏性变更**：33 处 `<Grid item xs=\>…` 旧 API 用法。新增 `src/components/CompatGrid.tsx`（包装 GridLegacy）并迁移 11 个文件的 import。
3. **`"use client"` 指令缺失**（Next 15 App Router 规则）：`OfflineNotification`、`AdaptiveExercises`、`LearningGroup`、`DownloadContentButton`、`AdaptiveLearningPath` 补上指令；`layout.tsx` 移除 Server Component 中非法的 `next/dynamic ssr:false`。
4. **前端误引用后端配置**：`AdaptiveExercises`/`LearningGroup` 的 `import { API_URL } from "../config"` 指向不存在文件，新建 `src/config.ts` 统一收敛。
5. **类型错误修复**：`offlineManager.ts`（Background Sync 类型、foundProgress 隐式 any）、`AdaptiveLearningPath`（antd Divider orientation）、`AdaptiveExercises`（prev 类型）、`page.tsx`（React import、SvgIcon fontSize prop 传响应式对象导致 MUI capitalize 崩溃——首页 500 根因）。
